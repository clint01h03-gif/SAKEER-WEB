Tech Zone Tuition Academy
========================

Simple static website for Tech Zone Tuition Academy (Sri Lanka).

Pages
-----
- index.html     → Home
- about.html     → About
- courses.html   → Courses
- teachers.html  → Teachers
- contact.html   → Contact / Join Now
- update.html    → Redirects to home update section

How to open
-----------
1. Unzip the folder
2. Open index.html in any browser (Chrome, Firefox, Edge, etc.)
3. No login needed — site opens directly
